# Sistema de Gestion de Pacientes

## Descripcion del proyecto

Sistema de gestion de pacientes desarrollado en C# utilizando Windows Forms.

El Sistema de Gestion de Pacientes permite registrar y administrar la informacion de pacientes mediante una interfaz grafica.

El programa permite realizar las operaciones principales de un CRUD:

- Registrar pacientes.
- Consultar pacientes.
- Editar pacientes.
- Eliminar pacientes.
- Buscar pacientes por ID o nombre.

El sistema permite:

- Agregar nuevos pacientes.
- Buscar pacientes por ID o nombre.
- Editar la informacion de un paciente.
- Eliminar pacientes.
- Validar los datos introducidos.
- Manejar errores mediante excepciones.

## Tecnologias utilizadas

- C#
- Windows Forms
- Visual Studio
- .NET
